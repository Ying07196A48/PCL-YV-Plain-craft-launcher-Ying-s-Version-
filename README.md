# PCL YV

**Plain Craft Launcher — Ying's Version**

> **本项目是基于 [Plain Craft Launcher 2（PCL2）](https://github.com/Meloong-Git/PCL) 独立进行二次创作的第三方修改分支，不是官方版本。**
> 与龙腾猫跃、PCL 官方无任何隶属关系，也不代表官方立场。

---

## 这是什么

PCL YV 是对 PCL2（龙腾猫跃开发的 Minecraft 启动器）的个人二改版本，在原版基础上做了一些自定义调整与功能改动。

- **原作者**：龙腾猫跃（[B站](https://space.bilibili.com/11343203) · [爱发电赞助](https://meloong.com/afd/a/LTCat)）
- **原仓库**：<https://github.com/Meloong-Git/PCL>
- **本修改版作者**：Ying
- **基础版本**：PCL 2.13.1.1（快照分支）

## 本修改版做了什么

- 自定义顶部导航布局，将「关于」独立为顶级页面
- 调整「更多」页面子项（精简帮助等入口）
- 其他个人化修改

## 使用方式

1. 从 Releases 下载最新版压缩包；
2. 解压后运行 `Plain Craft Launcher 2.exe`；
3. 首次启动按提示配置 Java 与游戏目录。
