# PCL YV

**Plain Craft Launcher — Ying's Version**

> 本项目是基于 [Plain Craft Launcher 2（PCL2）](https://github.com/Meloong-Git/PCL) 的第三方修改分支，**非官方版本**，与龙腾猫跃及 PCL 官方无任何隶属关系。

---

## 简介

PCL YV 是对 PCL2（龙腾猫跃开发的 Minecraft 启动器）的个人二改版，在原版基础上做了自定义调整与功能改动。
|---|---|
| **原作者** | 龙腾猫跃（[B站](https://space.bilibili.com/11343203) · [爱发电](https://meloong.com/afd/a/LTCat)） |
| **原仓库** | <https://github.com/Meloong-Git/PCL> |
| **本版作者** | Ying |
| **基础版本** | PCL 2.13.1.1 |

## 二改内容

- 顶部导航将「关于」独立为顶级页面，保留原作者署名与赞助入口
- 精简「更多」页面子项，调整导航布局
- 其他个人化修改

## 许可证

本项目**继续遵循上游 PCL 仓库的《PCL 分发有限许可》与《PCL 存储库合理使用指南》**，详见根目录 [LICENCE](./LICENCE)。

根据该许可，本项目属于"重度使用"：

- 明确声明为第三方基于 PCL 的独立二创产物；
- 名称以 "Plain Craft Launcher (PCL)" 开头并附加修改后缀（Ying's Version）；

**请勿将 PCL YV 误认为官方 PCL，也请勿以原作者名义发布或宣传。**

## 使用

1. 从 Releases 下载最新压缩包；
2. 解压运行 `Plain Craft Launcher 2.exe`；
3. 首次启动按提示配置 Java 与游戏目录。

> 本修改版为个人作品，无官方支持。
